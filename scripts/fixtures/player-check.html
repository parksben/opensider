The page runs its own integrity check on start and on every frame — the shape that makes a byte-dance flavoured player bundle refuse to play. OpenSider must never trip this on a tab the Agent is not working with; on a tab it does work with you should see it go red while the side panel is open, and go back to running (fresh check) once the panel closes.

Background tabs get no frames: if you leave this tab, rAF freezes (that is what OpenSider's page-activity feature is for). The buttons simulate the main-world hooks from inside the page, so this can be checked in any browser — no extension needed.
