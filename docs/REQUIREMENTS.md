# Cursor Sidebar — 需求文档

> Chrome 侧栏插件：用侧栏自己的聊天面板与本机 Cursor Agent 对话，支持多会话、从节点分叉和中英界面，并让 Agent 读取和操作当前浏览器页面。

## 产品目标

用户在 Chrome 里打开侧栏，就能和本机 Cursor CLI Agent 聊天。Agent 继续使用本机全部工具（读文件、改文件、跑命令等）。侧栏实时展示工具调用过程，效果对齐在终端 / IDE 里和 Agent 聊天。

所有网页共用**同一个工作区**，因此可以做跨页面的连续工作。聊天本身是**多会话**：用户可以新建、切换，也可以从某一轮对话之后的位置 fork 出新会话。切换标签时，Agent 能知道用户现在在哪个页面，并能抓取页面信息、直接操作页面完成自动化。

## 非目标（v1）

- 不另起用户需要手动启动的本地 HTTP / WebSocket 服务
- 不通过 MCP 暴露页面能力
- 不支持 Firefox / Safari
- 不执行页面里的任意 JavaScript（只开放白名单方法）
- 不把聊天同步到云端
- 不上架 Chrome Web Store（先以未打包扩展加载）

## 用户可见行为

### 安装与连接

1. 用户完成本机 Cursor CLI 登录（`agent login`）。
2. 用户安装 Native Messaging Host（由浏览器按需拉起，不是常驻服务），并以未打包方式加载本扩展。Host 的可执行副本装在 `~/.cursor-sidebar/runtime`，不从 Desktop 上的仓库直接拉起：macOS 会拦 Chrome 执行 Desktop / Documents / Downloads 里的脚本，表现为「Native host has exited」。
3. 点击工具栏图标打开 Side Panel。顶栏从左到右：左侧是连接状态（**仅启动中 / 离线 / 出错时出现**，已连接不展示「已连接」字样和图标）和当前页 favicon；中间是会话标题 + 紧贴右侧的无边框重命名按钮（Lucide `Pencil`，tooltip「重命名 / Rename」）；右侧依次是新会话、历史会话、开关灯、语言切换。已连接时左侧只剩 favicon。offline 时状态旁有「重连 / Connection」（旋转箭头 icon 已表示重试，英文不再写 Retry）。favicon hover 弹出两行：网页标题 + 完整 URL（取不到图标用 Globe）。不再单独铺一条当前页 banner。不放插件名和 slogan。未连接时说明原因。重连必须真正重连 Native Host，不能因为端口已断开就静默失败。两套主题的正文、次要文案与背景对比度都要够读，不能在某一主题下糊成一团。
4. 点标题旁 `Pencil` 后，标题变成输入框，按钮换成对勾（`Check`）；回车或再点对勾提交并退出，Esc 取消。提交走现有手动标题（之后不被首条消息覆盖）。右侧「新会话」是 Lucide `MessageSquarePlus`，点了直接新建并切过去，不打开列表。右侧「历史会话」是 Lucide `History`（tooltip「历史会话 / Past chats」），打开居中模态：无关闭钮、无底栏、无新建按钮，顶部只有全宽筛选。遮罩半透明底加 `backdrop-blur-md`。列表按 `updatedAt` 倒序；筛选按标题不区分大小写。列表（含顶栏）最大高度为视口上下各留 200px，超出滚动。上下键循环高亮并滚入视口，回车切换并关闭；点遮罩或 Esc 关闭。再点历史会话按钮也可关掉。会话名相对 header 水平居中，最大宽度为左右两侧各留 32px，标题不换行；超出省略，hover 用原生 `title` 看全文。语言按钮仍是圆角描边：英文界面显示「中」，中文显示「EN」。开关灯三态：浅色 / 深色 / 跟随设备（`Sun` / `Moon` / `Monitor`）。
5. 连接成功后，Host 拉起 `agent acp`，复用已有登录，进入 Agent 模式（完整本地工具）。关掉再打开侧栏时，应回放最近一次连接状态，而不是一直停在离线。侧栏与 Service Worker 之间的端口断开时，不得抛未捕获异常（Chrome 扩展页里那种 `disconnected port object`），并应自动重连；不要停在「Lost connection to the extension service worker」就不再试。
6. 用户发送后，侧栏立刻出现用户气泡，输入框描边进入进行中动效，发送钮换成停止。不再另起一行「Agent is working」转圈。离线时发送会留下可见错误，而不是没有任何反馈。

### 聊天

1. 侧栏是唯一的对话入口。消息列表、输入框、进行中状态由侧栏自己渲染，不依赖 assistant-ui 的 runtime 选择器。空会话在消息区垂直居中放一个淡色 Lucide `MessageSquareMore`（矩形气泡带省略号，约 120px）和一行淡灰提示：发送消息，开始与 Cursor 就网页内容聊天。提示两侧各留约 200px，宽度够就不要换行；侧栏太窄再折行。
2. 用户气泡宽度随内容收缩，最大不超过消息列表区域总宽的 80%，靠右。用户发送消息后，该气泡固定在这一轮的位置，本机 Agent 的正文和工具调用只追加在它后面，不得写进上一轮回复里把这条气泡往下挤。输入框占位固定提示「回车发送，Shift+回车换行」，不随连接状态变化。文本输入区默认高度为 2 行正文；内容变多时跟着长高，满 10 行后出现滚动，并始终把光标所在行滚进可视区。当前会话进行中时，输入框描边换成 Chrome Logo 四色圆锥渐变（红 `#EA4335`、黄 `#FBBC05`、绿 `#34A853`、蓝 `#4285F4`），先过渡铺满 360°，再以 4 秒一圈持续旋转；结束后整圈淡出，回到原来的细线，不要把描边收起来。输入区和工具栏分两行：第二行左侧是拾取元素、加号（添加附件）、权限模式下拉（默认权限 / 全部允许；菜单每项是模式名 + 灰色小字解释，文案对齐 Copilot：Asks when approval settings don't apply / Runs tool calls without asking），右侧是模型选择和发送钮。发送钮用 Lucide 小飞机纯图标；进行中换成停止图标。所有纯图标按钮都有 tooltip，须完整落在侧栏视口内并与边缘留出安全距离，不得被裁切。除顶栏按钮外，其余按钮（输入区、新建会话、会话卡片操作、Agent 回复下的 fork / 重新生成、权限条等）hover 为半透明覆盖（深色偏白、浅色偏黑），点击有 CSS 涟漪。会话列表按钮打开居中模态。
3. 加号由 Native Host 直接拉起本机选文件程序（`PickFiles` 到前台，失败再走访达 `choose file`），可一次多选文件和/或文件夹。未连上 Host 时加号会留下可见错误，不能静默没反应。输入框支持直接粘贴截图（或剪贴板里的图片）：粘贴后进入同一套附件芯片，随这条消息一起发出；同一张图只生成一个芯片，不要因为剪贴板同时带 files / items 就写两份。未连上时留下可见错误，不能只把图片糊进文本框。拾取按钮用光标 icon：点后**整栏**立刻被带背景模糊的遮罩盖住，提示叠在遮罩上；点遮罩不取消。网页进入拾取态（十字光标、悬停高亮），再点一下即拾取。遮罩和提示只在拾取完成或按 Esc 后消失。已打开的 http(s) 页即使还没注入过内容脚本，点拾取也会补上，不必先刷新。选中后在文本框上方以芯片展示。文件芯片和拾取元素芯片同一套尺寸：最大宽度约 200px，超出省略，悬停用 title 看全文；图片 / 普通文件 / 文件夹 / 拾取元素用不同 lucide 图标；芯片右侧可删。文件附件发给 Agent 的是本机绝对路径，不上传内容。元素附件带全局唯一 CSS Selector（等同 DevTools「复制 selector」），并说明这是用户在当前页拾取的节点，供 Agent 查看或操作。没有正文、只有附件时也可以发送。
4. 未连上时不展示模型下拉。连上后只展示 Host 从 `agent models` / ACP `configOptions` 拉到的列表，不自己再塞选项。列表顶部有一个固定筛选框（不随条目滚动，无边框 / outline），弹出后自动聚焦，按已加载的名称或 id 做不区分大小写的包含匹配；中文占位为「筛选...」。上下键在当前筛选结果里循环移动高亮（向下超出最后一条回到第一条，向上超出第一条落到最后一条），列表跟着滚到高亮项；回车切换到高亮模型。列表里若有 CLI 的 `auto`，下拉默认选中它（表示不指定，不发给 ACP）。用户后来选了具体模型才写入本机并作用到当前会话；下次打开若仍记得该模型则保持，否则回到 auto。
5. Agent 调用本地工具时，侧栏用灰色小字展示：左侧 lucide 图标标明 kind（读取 / 编辑 / 执行 / 搜索等），颜色与灰字一致，旁边是工具标题（路径或查询原文保留）。不要做成带边框的卡片。点开后往下展开，内容最多约 5 行，超出才滚动；不足则盒子跟着内容变矮，不要写死高度。边缘渐变遮罩与过程区相同。进行中标题左侧只显示同色细转圈，不要和 kind 图标并排；转完再换成 kind 图标。流式进行中，若连续多段思考 / 工具中间没有正文，只保留最后一条占同一行，不要一条条往下堆；整轮结束后用户展开「此次执行」才把每一步平铺成各占一行。
6. Agent 请求权限时，默认「默认权限 / Default permissions」模式：侧栏在消息列表与输入框之间弹出允许一次 / 始终允许 / 拒绝，不自动静默放行写文件和执行命令。询问正文最多约 9.5 行，超出滚动，按钮始终露在外面。输入栏附件按钮右侧点开权限菜单：每项第一行是模式名，下面一行灰色小字解释（英：Default permissions / Asks when approval settings don't apply；Allow all / Runs tool calls without asking。中：默认权限 / 当审批设置不适用时询问；全部允许 / 无需询问即可运行工具调用）。选「全部允许 / Allow all」后工具权限自动选「始终允许」（没有则选「允许一次」），不再弹卡片；提问和计划审批仍要人点。模式写入本机，下次打开仍是上次的选择。当前已弹出的权限卡切到全部允许时立刻自动放行。
7. Agent 下发的提问、计划审批、todo 更新，在侧栏可见并可回应。权限 / 提问 / 计划卡片都落在输入框上方（不在输入框下面）；正文同样限高约 9.5 行。Agent 规划的 todo 也不挂在顶栏下，而是同样落在输入框上方：标题栏为「Todo List - 已完成/总数」（如 Todo List - 3/3），右侧是展开/收起箭头，点击整行标题即可折叠；完成项右侧用带圆圈的对勾 icon（Lucide `CircleCheck`）表示。用户收起后，下次 Agent 再规划出新的 todo（条目 id 或文案变化）时自动展开。思考过程也是灰色纯文本折叠（「思考 / Thinking」+ 紧挨着的箭头），去掉空行，点开后同样向下展开：最多约 5 行，超出才滚动，不足则贴内容高度，边缘渐变遮罩。Agent 回复里的 ` ```mermaid ` 围栏：`flowchart` / `graph` 用轻量 SVG（`@dagrejs/dagre` 布局，不引入 mermaid 包）画成图；其它类型或解析失败仍显示原来的代码块。不得往 `body` 挂报错 SVG。输入框打字不得让消息列表重跑图或抖动。Agent 正文里的链接：若与当前浏览器标签页是同一域名（主机名忽略大小写，`www.` 视为同一站点），点击后在**当前标签**跳转，不要新开标签；域名对不上，或当前没有可用的 http(s) 标签，再新开标签。只处理 `http(s)`。按住修饰键点击一律新开标签，避免把侧栏自己导航走。一轮流式输出**结束之后**，只留下最后一段非思考、非工具调用的正文；思考、工具调用以及它们之前的内容全部折起。收起时是一行灰色纯文本，说明此次执行花了多久（如「此次执行用了 12 秒 / Worked for 12s」）；没有记下时长的旧消息只写「已执行 / Worked」。箭头紧挨文案，不要居整行右侧，也不要做成整行色块或按钮底。鼠标悬停某一行时，只在这一行文案旁出现向右箭头，不要把同条消息里其它工具 / 思考 / 过程行的箭头一起亮出来。整行都可点，但视觉上只是灰字加箭头；点开后箭头改为向下，过程**往下展开**，灰字那一行不要被顶走。过程区只设最大高度、内部可滚，内容不够高时盒子跟着变矮，不要写死高度，避免长过程把后面的正文顶出屏幕。滚动时用混合模式做边缘渐变：还没滚到顶则上方从不透明到透明，还没滚到底则下方从透明到不透明。再点折起。进行中不出现耗时行：连续思考 / 工具（中间无正文）只显示当前最后一条，方便看正在做哪一步。整轮结束后过程先收成耗时行；用户再展开时，这些步骤才按每条一行平铺。若这一轮只有正文、没有过程，就不出现这一行。
8. 用户可中断当前一轮。
9. 用户可点击已发送的用户气泡，把正文和附件带回输入框修改。输入框顶部左侧提示「正在修改历史消息，重新发送后，该位置后的全部内容将重新生成」（英：Editing a past message. Resending will regenerate everything after this point.），右侧纯文本「取消修改 / Cancel edit」，用主题强调色（深色黄铜 / 浅色钢蓝），带 hover 和点击涟漪。重新发送后该条被替换，其后全部丢掉并重跑。进行中不可点气泡。
10. 有消息后列表仍用 `flex-col-reverse` 做贴底滚动：发送和流式输出时自动跟随；用户往上翻则停止跟随；再滚回靠近底部（约 96px 内）则恢复跟随。内容还没撑满消息区时（空会话刚发出第一条、Agent 还没写很长），消息从**顶部**排，不要贴在输入框上方；只有正文把区域撑满后，旧消息才被顶上去。离开底部超过该距离时，输入框上方浮一层圆形「回到底部」按钮：绝对定位盖在消息上，不占一行、不把列表挤矮。贴底、刚离开几像素、或继续往底外弹性滚动时都不要出现；从底部往上滚时，距底未超过约 96px 保持隐藏，超过后稳定展示，不要先显后隐再显。水平相对输入区居中，上方留约 16px。直径约为原先 56px 的 0.7（约 39px）。默认半透明底 + 轻投影，好和底下的消息分开；hover 时不透明度升高；点击有涟漪。带 tooltip。

### 工作区与会话

1. 所有页面共用一个工作区：`~/.cursor-sidebar/workspace`。页面工具、快照、命令文件不随聊天会话切换。
2. 聊天是多会话。侧栏可新建、切换、重命名、删除会话。会话卡片上有重命名和删除按钮。手动改过的标题不会被后续消息覆盖。删掉当前会话会切到另一条；删光则自动新建一条。关掉侧栏或换标签不会自动新建。
3. 当前选中的会话、每个会话的标题和消息历史，关掉侧栏再打开仍然在。Host 重启后尽量 `session/load` 回对应的 ACP 会话；失败则新建 ACP 会话，界面历史仍保留，下一条用户消息会带上此前的摘要上下文。卸载或重新安装扩展会清掉 `chrome.storage.local`，侧栏气泡会空；ACP 工作区里的会话还在，但不得把 `session/load` 回放的整段 prompt 画成一条用户气泡。已经坍成一条的本地记录，打开时尽量按 `User:` / `Assistant:` 拆回多轮，并去掉 `[Current tab]` / fork 包装前缀。用户气泡和会话标题也不展示这行环境前缀。
4. 用户可从任意一轮 **Agent 回复** **fork**（用户气泡下不放）：原会话不动，新会话复制该回复及之前的消息，之后独立往下聊。不做 checkpoint。中文 tooltip 为「从此处复制新会话」，英文为 Fork from here。
5. Agent 回复底部一行只在 hover 时出现：左侧灰色字说明此内容由哪个模型生成（如「由 Auto 生成 / Generated by Auto」），右侧无边框 **复制**、Fork 与 **重新生成**（刷新 icon）。复制只写入这一轮可见正文的 Markdown，不含已折起的「此次执行 / Worked」过程（思考、工具调用、过程前的正文）。点复制成功后，Copy icon **原地**换成对勾（Lucide `Check`），约 1.5 秒再切回；成功反馈期间这一行保持可见，不必一直悬停。本轮还在流式输出时，最后一条回复上这一行无论是否 hover 都不出现，结束之后才可以。重新生成会丢掉该轮及之后的 Agent 回复，用同一条用户消息再跑一遍，不另开会话。中间轮次重跑会截掉后面的对话。中文 tooltip 为「复制 / 已复制 / 重新生成」，英文为 Copy / Copied / Regenerate。用户气泡上方间距是普通消息间距的两倍（24px），跟上一轮 Agent 回复拉开。
6. 多个会话可以同时跑不同任务。某一轮还在进行时，仍可新建会话或切到别的会话继续发；流式更新必须写回**发起这一轮的会话**，不得因为后来选中了别的会话而写错地方。切走之后，输入框的进行中态、停止钮和权限/提问/计划卡片只属于当前正在看的会话：回到那个会话才能看到并处理。对某个会话做 fork、重新生成或改历史再发时，只在**该会话自己**正在跑时拒绝。重命名随时可以。删除正在跑的会话会先取消这一轮再删。

### 语言

1. 界面只做中英两种。默认英文。
2. 顶栏最右侧按钮切换 English / 中文。界面中英都不使用衬线体。
3. 语言选择写入本机，下次打开仍是上次的选择；打开侧栏第一帧就要用上次的语言，不要先闪默认英文再切回去。
4. Agent 工作区说明（`AGENTS.md`）保持英文，不随界面语言切换。

### 主题

1. 界面有浅色、深色两套，另可跟随系统 `prefers-color-scheme`。默认深色（与现有侧栏一致）。
2. 顶栏语言按钮左侧的开关灯循环：浅色 → 深色 → 跟随设备 → 浅色。tooltip 为当前状态（浅色 / 深色 / 跟随设备；英 Light / Dark / Match device）。
3. 主题选择写入本机，下次打开仍是上次的选择；打开侧栏第一帧就要用上次的主题，不要先闪默认深色再切回去。跟随设备时系统改明暗，侧栏立刻跟着变。
4. 浅色是柔和、有层次的中性浅灰（浅灰画布 + 近白抬升面 + 钢蓝强调），不要暖黄纸色，也不要发脏的蓝灰底。正文、muted、链接/强调色、用户气泡、代码块在两套主题里都对背景保持足够对比，禁止浅色主题继续用深色专属的浅字或深底。

### 页面感知与操作

1. 用户切换 Chrome 标签或当前页 URL 变化时，扩展更新「当前页」状态。
2. 侧栏不再用 banner 展示当前页标题与 URL；顶栏左侧（连接状态右边，已连接时就是左起第一个）只显示 favicon，hover 看标题和完整 URL。Agent 正在执行页面命令时，顶栏仍显示该方法名和结果。
3. 每条用户消息在发给 Agent 时附带一行当前页上下文（标题 + URL），界面里只显示用户自己输入的文字。
4. 内容脚本向页面注入一套白名单方法。Agent 通过工作区命令文件调用，不走 MCP。
5. **读取**：元信息、正文、选区、链接、标题大纲、按选择器取文本 / 属性 / 值、列出匹配元素、判断元素是否存在。
6. **操作**：点击、双击、悬停、聚焦、填写、追加输入、清空、下拉选择、勾选、按键、滚动、等待元素、导航、前进 / 后退 / 刷新。
7. **视觉**：截当前视口，或把指定元素滚入视口后截该元素。图片落到工作区文件，供 Agent 用视觉理解布局、对照文案、规划下一步点击。
8. 定位元素可用 CSS 选择器，或可见文本（可再加 `nth`）。点击前滚动到元素并短暂高亮。
9. 填写控件时派发 input/change，以便 React / Vue 等受控输入能收到。
10. 导航只允许 `http(s)`。操作完成后刷新当前页快照。
11. Host 启动、会话建立时，工作区已写好 `AGENTS.md` 和 `browser/tools.json`。Agent 在插件连上的第一时刻就能读到全部页面方法（含截图），不必等用户再说明。
12. 以下页面不注入、不抓取、不操作、不截图：`chrome://`、`chrome-extension://`、Chrome Web Store。
13. 页面自动化默认执行，不再逐步弹权限（用户装这个扩展就是为了让 Agent 动手）。本地文件写入和 Shell 仍走 ACP 权限条。

### 跨页工作

因为工作区固定，用户可以在 A 页讨论、切到 B 页继续，让当前会话结合两页信息和本机文件做更复杂的事。换一个会话不会丢掉工作区里的页面快照，只是换一条聊天上下文。

### 状态持久化

再次打开侧栏时恢复：界面语言、主题偏好、权限模式、会话列表、当前选中会话、每个会话的消息、上次选的模型。不把聊天同步到云端，只存在本机扩展存储和 Host 侧的会话索引。附件只存在未发送的输入栏里，不单独云同步。

### 品牌图标

1. 图标外形用 Cursor 官方立方体 Logo（品牌资源包 `CUBE_2D` 六边形轮廓），不再垫圆角方形底。
2. 立方体本体填充 Google 三色顺时针旋转风车（参考 Chrome 图标视觉）：红 `#EA4335`（上）→ 黄 `#FBBC05`（右下）→ 绿 `#34A853`（左下）。
3. 三色交界为直线，但交界带做平滑渐变过渡（约 40° 宽），不出现生硬颜色边界；每色核心区域保持纯色。
4. 立方体中央的光标区域保持透明镂空（随背景透出），不填色。
5. 图标由 `scripts/generate_icon.py` 生成（360 个 1° 扇形逼近 conic 渐变），导出 16/32/48/128 PNG 供 manifest 使用。

## 决策记录

| 决策 | 选择 | 原因 |
|---|---|---|
| UI | 自研 ChatPane（lucide） | assistant-ui ExternalStore 的 `useAuiState` 与消息状态不同步，表现为发了没动效、也停不了 |
| 浏览器 | 仅 Chrome | Side Panel + Native Messaging 最成熟 |
| 与 CLI 的连接 | Native Messaging Host 拉起 `agent acp` | 扩展无法 spawn 进程；Host 由 Chrome 按需启动，不是常驻服务 |
| 页面工具 | 内容脚本 + 工作区文件 RPC | 读和写都走同一通道，不必上 MCP、不必再开端口 |
| 页面自动化权限 | 白名单方法默认执行 | 逐步确认会打断自动化；系统页仍然隔离 |
| 页面截图 | 视口 / 元素 JPEG 写入工作区 | Native Messaging 有 1MB 上限，不能传原图；Agent 用 Read 看图片做视觉规划 |
| 能力发现 | 启动时写 AGENTS.md + tools.json | 会话 cwd 里第一眼就能看见全部方法 |
| 工作区 | 全局单一目录 | 跨页连续工作，页面工具不跟会话走 |
| 会话 | 多会话 + 本机持久化 | 用户要新建 / 切换 / 保留历史 |
| Fork | 从某一轮 Agent 回复分出新会话 | ACP `session/fork` 目前不能指定消息；节点分叉用新会话 + 首条上下文 |
| 重新生成 | 同一会话丢掉该轮回复再跑 | 旧 ACP 历史含上次回复，所以换 `session/new` + 前文再 prompt |
| 改历史消息 | 点用户气泡带回输入框再发 | 替换该条、截掉之后，复用重新生成的 `session/new` + 前文 |
| 语言 | 英（默认）/ 中，本机记住 | 只要两种，默认英文 |
| 主题 | 浅 / 深 / 跟随设备，本机记住 | 三态开关灯；token 化颜色保证两套对比度 |
| Agent 模式 | `agent`（完整本地工具） | 用户要求本地工具可用，且过程要在 UI 里看见 |
| 附件 | 文件只传本机路径；元素只传 CSS selector | 扩展拿不到真路径；元素给 Agent 定位，不必上传 DOM |
| 模型 | `agent models` + ACP `configOptions` | 与 Cursor 账号当前可选模型对齐，而不是写死一份 |
| Mermaid | `flowchart`/`graph` 用 dagre SVG；其它类型回退代码块 | mermaid 包太重且会污染 DOM、打字时重绘抖动；扩展 CSP 下 HTML 节点也常画不出来 |
